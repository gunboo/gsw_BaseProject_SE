미술 방향
  스토리_확장안과 최신 스토리_조사_설계를 참고한 일본 중세 판타지.
  낡은 목재, 흙벽, 종이, 볏짚, 먹빛 기와, 돌, 철, 삼베를 사용.
  차분한 쪽색·이끼색·흙빛이 기본이며 원령은 청록, 봉인은 탁한 붉은색.
  외부 모델과 이미지, 유료 생성 모델은 사용하지 않은 자체 제작 리소스.

인간 조합
  기준 키 1.75m, 기준 머리 길이 0.25m인 7등신. 하나는 같은 비율에 균일 축소하여 1.25m.
  얼굴 3종, 머리카락 4종, 의복 4계열, 좌우 소매, 바지 2계열, 발 2계열,
  수염·삿갓·허리띠·앞치마·도검·찰갑 부품을 조합한다.
  같은 슬롯의 옷과 몸통을 동시에 겹쳐 넣지 않는다. 바지에는 Clothes_Pelvis를 사용한다.
  완성 GLB를 기준 골격으로 사용하고 교체 부위는 뼈 이름으로 기존 골격에 바인딩한다.
  부위 GLB에 포함된 골격은 기준 정보이므로 조합할 때마다 추가 생성하지 않는다.
  얼굴 표정 모프나 손가락 관절은 포함하지 않는다. 얼굴 교체는 머리 메시 단위다.

동물 조합
  사슴: 중립 초식 / 늑대: 위험 육식 / 멧돼지: 자극 시 위험한 중립 잡식 / 염소: 온순 초식.
  뒷다리는 고관절→앞쪽 무릎→뒤쪽 비절→중족부→발굽/발바닥으로 구성.
  늑대는 발가락 보행, 나머지 종은 갈라진 발굽을 사용한다.
  부위 교환은 같은 종의 골격 안에서만 한다. 사슴 Antlers를 숨기면 뿔 없는 조합.
  성향은 리소스 분류용 메타데이터이며 AI 행동은 포함하지 않는다.

애니메이션
  24fps. 사람: Idle, Walk, Run, 좌우 90도 회전, Attack, Jump,
  WalkStart, WalkStop, RunStop, JumpStart, JumpAir, JumpLand,
  Reference_TPose, Reference_APose, TurnBase = 16개.
  동물: 위 구성에서 T/APose 대신 Reference_Stand 사용 = 종마다 15개.
  공격은 사람의 도검 베기, 사슴 뿔 밀기, 늑대 덮쳐 물기 표현,
  멧돼지 엄니 들이밀기, 염소 박치기로 구분한다.
  걷기/뛰기는 제자리 이동이다. nominalSpeedMps를 액터 이동과 재생 속도의 기준으로 사용한다.
  Walk→Run 0.20초, Run→Walk 0.22초 블렌딩을 시작값으로 권장한다.
  두 보행의 정규화 위상을 맞추고 접지한 발을 기준으로 전환한다.
  인간은 좌우 접지 0/0.5, 동물은 앞왼발 기준 위상을 사용한다.
  4박 걷기와 캔터/트로트 달리기의 나머지 발 위상은 JSON에 따로 기록했다.
  TurnBase는 회전 보간을 위한 정지 기준 포즈다.
  회전 클립의 root yaw를 액터 방향에 반영한 뒤 root의 로컬 회전을 정리한다.
  전체 Jump는 골반 높이에 포물선형 시각 동작을 포함한다.
  물리 점프를 구현할 때는 JumpStart→JumpAir(공중 루프)→JumpLand 조합을 사용한다.
  전체 Jump와 액터의 수직 점프를 중복 적용하지 않는다.
  제안된 블렌딩 시간은 게임에서 조정 가능한 시작값이다.
  지형 적응 IK, 피격 판정, 상태 머신, 게임 엔진 연결은 별도 작업이다.

Blender에서 확인
  EN_Characters / EN_Animals / EN_Architecture / EN_Props / EN_Nature 컬렉션을 사용한다.
  HUMAN_7H_V2과 개별 원형 부품은 겹침 방지를 위해 숨겨져 있다.
  이를 표시하면 교체 부위가 같은 바인드 공간에 정렬되어 있음을 확인할 수 있다.
  완성 캐릭터의 Armature를 선택하고 Action Editor에서 Human_ 접두사의 액션을 선택한다.
  동물은 Deer_/Wolf_/Boar_/Goat_ 접두사 액션을 사용한다.
  NLA에는 내보내기용 클립 트랙이 있으며 모두 음소거 상태다.
  단일 액션을 재생할 때는 해당 액션을 활성화하고 타임라인 범위를 맞춘다.
  원본 .blend는 텍스처를 포함하며, GLB에도 사용한 텍스처가 포함된다.

검증 범위
  GLB 내부 스킨/JOINTS_0/WEIGHTS_0, 애니메이션 목록, 파일 구조와
  원본 메시의 뼈 가중치 정규화를 검사하고 Blender 정지/동작 렌더로 확인.
  게임 프로젝트 코드는 변경하지 않았으며 엔진 내 실행 검증은 하지 않았다.
